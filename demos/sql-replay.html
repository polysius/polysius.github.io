Recorded text-to-SQL runs

From the text-to-SQL agent. Every question in the benchmark, the SQL the agent wrote, and the SQL it should have written.

This is a recording, not a live model. The agent needs a database and an LLM, which a static page cannot host for free. These are the saved results of one benchmark run per database. A question counts as correct when the agent's query returns the same rows as the reference query, so a correct answer can use different SQL.
